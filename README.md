# zmk-config-roBa (右手基板検証用カスタム)

オリジナル設計の右手側キーボード、およびトラックボール（PMW3610）の動作検証を行うためのZMKファームウェア設定リポジトリです。

## 📂 リポジトリのツリー構造と各ファイルの役割

```text
zmk-config-roBa/ (ルート階層)
├── .github/workflows/
│   ├── build.yml             ─── [GitHub Actions] クラウド自動コンパイルの手順書
│   └── draw.yml              ─── [Keymap Drawer] キーマップ自動画像化の実行スクリプト
├── boards/shields/roBa/       ─── ★【HAL / ハードウェア定義層】物理的な配線ピンの設定
│   ├── Kconfig.defconfig     ─── 画面（OLED）などのシステム全体のデフォルト初期値
│   ├── Kconfig.shield        ─── "roBa_L" や "roBa_R" という盾（シールド）の名前をシステムに登録
│   ├── roBa.dtsi             ─── 左右共通の骨組み（行ピン `D1, D2, D3, D6` や物理キー配列の定義）
│   ├── roBa.zmk.yml          ─── ZMKのメタデータ（キーボード名や製作者情報）
│   ├── roBa_L.conf           ─── 💥有線単体テスト化（`SPLIT=n`）やエンコーダー停止（`EC11=n`）を制御するフラグ
│   ├── roBa_L.overlay        ─── 💥右手用列ピン（`D10〜D7, NFC2`）およびトラックボール（SPI通信）の物理アサイン
│   ├── roBa_R.conf           ─── 本来の右手用設定フラグ（今回は不使用）
│   └── roBa_R.overlay        ─── 本来の右手用物理ピン定義（今回は不使用）
├── config/                   ─── 【アプリケーション層】実際の配列やキーレイアウトの設定
│   ├── roBa.json             ─── 各キーが画面上のどの座標（見た目）に配置されているかのレイアウトデータ
│   └── roBa.keymap           ─── 実際のキー配列。どのキーを押した時にどの文字（A, S, D等）をPCに送るかの設定
├── keymap-drawer/             ─── キーマップの視覚的な配列図を自動生成するための作業フォルダ
│   ├── roBa.svg              ─── 自動生成されたキーマップの画像ファイル（ベクター画像）
│   └── roBa.yaml             ─── キーマップ画像を出力するための定義ファイル
├── zephyr/                   ─── ZMKのベースOS（Zephyr OS）へ外部ドライバを追加するためのモジュール設定
│   └── module.yml            ─── 非公式のPMW3610用光学センサードライバを読み込ませる指示書
├── README.md                 ─── ★本ドキュメント
└── build.yaml                ─── ZMK全体のビルド対象シールドを指定する大元の設定ファイル
```

## 🔬 現在の右手有線検証用の設定詳細

現在、右手基板単体での動作検証を100%確実に行うため、以下のファイルに特殊な「引き算デバッグ」の設定を肉付けしています。

### 1. `boards/shields/roBa/roBa_L.conf`
左右分割通信の待ち受けループによるフリーズ、およびD0ピンの競合を回避するため、以下のビルドフラグを最下部に追加しています。
* `CONFIG_ZMK_SPLIT=n` : 左右のワイヤレス通信を完全にシャットダウンし、1台の有線キーボードとしてブートさせる。
* `CONFIG_EC11=n` : D0ピン（MOTION）を裏で占有していたロータリーエンコーダーの初期化タスクを完全に無効化し、ピンをセンサー専用に解放する。

### 2. `boards/shields/roBa/roBa_L.overlay`
コンパイラ（Zephyr OS）に怒られた「SPIの物理ピン設定（`pinctrl`）」の不足を修正し、右手用のマトリクス列ピンとPMW3610の通信ピンを正確にマッピングしています。
* **列ピン（Col）**: `D10`, `D9`, `D8`, `D7`, `NFC2 (P0.10)`
* **センサー（SPI）**: `SCLK=D5`, `SDIO=D4`, `CS=NFC1 (P0.09)`, `MOTION=D0`
